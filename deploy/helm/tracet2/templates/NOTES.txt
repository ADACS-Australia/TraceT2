TraceT2 has been deployed!

1. Get the application URL:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}
{{- end }}
{{- else if contains "NodePort" .Values.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "tracet2.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "ClusterIP" .Values.service.type }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "tracet2.fullname" . }} 8080:{{ .Values.service.port }}
  echo http://localhost:8080
{{- end }}

2. Create an admin user:
  kubectl --namespace {{ .Release.Namespace }} exec -it deploy/{{ include "tracet2.fullname" . }}-web -- uv run ./manage.py createsuperuser

NOTE: The SQLite database is stored on a PersistentVolume at {{ .Values.persistence.mountPath }}.
      Both the web and listener deployments use strategy: Recreate to avoid concurrent SQLite access issues.
